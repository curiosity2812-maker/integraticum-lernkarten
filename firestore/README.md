# Сопреподаватели Integraticum

В кабинете владелец открывает «Преподаватели группы», создаёт одноразовый код нужной группы и передаёт его человеку. Получатель входит в свой аккаунт и выбирает «Ввести код преподавателя». Владелец нажимает «Обновить список», видит аккаунт, подавший заявку, и подтверждает его. Пока заявка не подтверждена, код можно отменить. После подтверждения кнопка «Убрать преподавателя» отзывает права на сервере. Код уже использован и повторно не активируется.

Сопреподаватель видит учебные наборы группы, публикует наборы в ней и обрабатывает заявки учеников. Управление приглашениями преподавателей остаётся у владельца. Глобальная роль в `users` не меняется. Опубликованные материалы остаются в группе при отзыве доступа. Если этот аккаунт уже состоит в группе как ученик, ученический доступ сохраняется.

## Подготовка к выпуску

1. Сохраните копию действующих правил базы Cloud Firestore проекта Integraticum. Включите содержимое `co-teachers.rules.inc` внутрь существующего блока `match /databases/{database}/documents`. Блоки для старых коллекций сохраняются.
2. Проверьте объединённые правила в эмуляторе. Для пересекающихся разрешений Firestore достаточно выполнения одного `allow`. В действующих правилах проверьте, что широкие разрешения не открывают записи `groupTeacherInvites` и `groupCoTeachers`, что право менять `groups.ownerUid` защищено и что общие правила для заявок, участников и наборов закрывают административные операции после отзыва доступа. Не используйте тестовую политику из скрипта как рабочие правила.
3. Сначала опубликуйте проверенные правила в Firebase и затем обновите GitHub Pages. Существующие группы, коды учеников и локальные данные остаются на месте. Новые коллекции создаются при первой записи.

## Проверка правил

Из корня репозитория можно установить `firebase-tools@14`, `@firebase/rules-unit-testing@5` и `firebase@12` во временный каталог. Запустите Firestore Emulator для демопроекта `demo-integraticum` и выполните:

```sh
FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 NODE_PATH=/абсолютный/путь/к/node_modules node firestore/test-co-teachers.cjs
```

Скрипт загружает фрагмент правил с минимальными подставными правилами для прежних коллекций. Проверку с действующими правилами повторите на объединённом файле, указав его путь в переменной `INTEGRATICUM_RULES`. Скрипт очищает данные демопроекта в эмуляторе.

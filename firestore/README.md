# Сопреподаватели Integraticum

В кабинете владелец открывает «Преподаватели группы», создаёт одноразовый код нужной группы и передаёт его человеку. Получатель входит в свой аккаунт и выбирает «Ввести код преподавателя». Владелец нажимает «Обновить список», видит аккаунт, подавший заявку, и подтверждает его. Пока заявка не подтверждена, код можно отменить. После подтверждения кнопка «Убрать преподавателя» отзывает права на сервере. Код уже использован и повторно не активируется.

Сопреподаватель видит учебные наборы группы, публикует наборы в ней и обрабатывает заявки учеников. Управление приглашениями преподавателей остаётся у владельца. Глобальная роль в `users` не меняется. Опубликованные материалы остаются в группе при отзыве доступа. Если этот аккаунт уже состоит в группе как ученик, ученический доступ сохраняется.

## Подготовка к выпуску

1. Сохраните копию действующих правил Cloud Firestore в проекте Integraticum. Файл `firestore.rules` содержит полный набор правил, подготовленный на основе предоставленной владельцем версии. Если правила проекта изменились с момента копирования, сначала учтите эти изменения.
2. Опубликуйте проверенный файл во вкладке Rules базы Cloud Firestore. Затем обновите GitHub Pages. Новые коллекции создаются при первой записи.

## Проверка правил

Из корня репозитория можно установить `firebase-tools@14`, `@firebase/rules-unit-testing@5` и `firebase@12` во временный каталог. Запустите Firestore Emulator для демопроекта `demo-integraticum` и выполните:

```sh
FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 NODE_PATH=/абсолютный/путь/к/node_modules node firestore/test-co-teachers.cjs
```

Скрипт загружает `firestore.rules` целиком. Он очищает данные демопроекта в эмуляторе.
